# Internal Policy QA Assistant — RAG Prototype

This project implements a Retrieval-Augmented Generation (RAG) system to answer questions on internal banking policies. Key features include:

- Document preprocessing and chunking
- Embedding generation for semantic search
- Vector database storage using Chroma
- Query processing with LLM to provide accurate answers
- Evaluation of relevance and correctness of responses

Demonstrates practical application of RAG in a banking context, supporting internal teams with AI-driven knowledge retrieval, operational guidance, and compliance assistance.
